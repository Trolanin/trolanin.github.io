      Flashing it to the ESP32
      

        
    
          
  1. Plug in the ESP32 and click Download .ino.
    2. 
          
  2. Drag the downloaded .ino onto flash.bat in the led-sim folder. It compiles, finds the ESP32's port, uploads, then starts led-audio.exe --port COM5 so the board gets audio (the simulator keeps getting it too).
    3. 
          
  3. Several serial devices plugged in? It asks which port. A specific one: flash.bat my_design.ino COM5.
    4. 
        

        
Using the Arduino IDE instead: install FastLED, pick "ESP32 Dev Module", upload, then close the Serial Monitor and run the led-audio command above — only one program can hold the COM port.

        
The design is saved inside the .ino (the LEDDESIGN line), so Import… on that file brings it back here for more tweaking.
